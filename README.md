# Ardub's RKA

A fork of [Rat King Adventure](https://github.com/TrashboxBobylev/Rat-King-Adventure), based on version 2.3.6.

## Changes

- Larger backpack and bags.
- Up to five cleric quick-cast spells.
- Portable selling with the Master Thieves' Armband and Soul of Yendor.
- Ankhs stack.

- Cenobite health capped at 1/2 normal, rather than forever not growing.
- Larger talent window.

- Cenobite talent rolling bugfixes
- Abyss trap pathfinding bugfix.
- Cooldown, artifact, and save bugfixes.
